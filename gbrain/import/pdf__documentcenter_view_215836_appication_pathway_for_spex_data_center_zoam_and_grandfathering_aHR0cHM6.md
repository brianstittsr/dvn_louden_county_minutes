 County staff put together this document to illustrate the application of the Zoning Ordinance
amendment and the Grandfathering Resolution adopted by the Board of Supervisors on March
18, 2025. The result reached by using this document will vary depending on the particular
circumstances of each specific land development application. Notwithstanding the
foregoing, if there is a conflict between this document and the Zoning Ordinance or the
Grandfathering Resolution, the Zoning Ordinance and the Grandfathering Resolution prevail.
Legislative Applications – Whether SPEX Required for Data Center Use
Grandfathering – If a legislative application is grandfathered, then a data center use can be
approved as part of a ZMAP, ZCPA, or ZRTD, and without a SPEX, assuming the proffers/CDP
provide enough detail about the data center use to establish a vested right or to come under
footnote 4. Keep in mind that a ZMAP, ZCPA, or ZRTD approved after February 12, 2025, up to and
including March 18, 2025, may still come under footnote 4 or establish a vested right. Additionally,
if an application is protected by the grandfathering for ZOR, then it is protected from the changes in
ZOAM-2024-0001.
Initial Grandfathering Determination
1) Was the legislative application accepted on or before February 12, 2025? If yes, then the
legislative application is grandfathered. Go to 2) to determine if grandfathering status is retained.
If no, then the legislative application is not grandfathered and a SPEX is needed.


Retention of Grandfathering Status
2) Have substantial modifications been made to the application after February 12, 2025? If yes,
then the legislative application lost grandfathered status and a SPEX is needed.
If no, go to 3).

3) Has applicant diligently pursued approval since February 12, 2025? If yes, then the legislative
application keeps grandfathered status and a SPEX is not needed.
If no, then the legislative application lost grandfathered status and a SPEX is needed.

Administrative Applications – Whether SPEX Required for Data Center Use
Grandfathering – If an administrative application for a data center is grandfathered, and does not
lose grandfathering status before it is approved, then the applicant is not required to get a SPEX
approved before the administrative application can be approved. Additionally, if an application is
protected by the grandfathering for ZOR, then it is protected from the changes in ZOAM-2024-0001.
Initial Grandfathering Determination
1) Was the administrative application accepted on or before February 12, 2025? If yes, go to 2).
If no, go to 8).

2) Is the administrative application for a data center use? If yes, go to 3).
If no, go to 8).

3) Was the data center use in the administrative application permitted by-right when the
administrative application was accepted? If yes, go to 4).
If no, go to 8).

4) Would the data center structure and external mechanical equipment shown on the
administrative application have been more than 500 feet from all existing residential structures on
February 12, 2025? If yes, then the administrative application is grandfathered. Go to 6) to
determine if grandfathering status is retained.
If no, go to 5).

5) Can the administrative application be revised so the data center structure and external
mechanical equipment shown on the administrative application would have been more than 500
feet from all existing residential structures on February 12, 2025? If yes, then the administrative
application will be grandfathered if applicant makes the revisions. Go to 6) to determine if
grandfathering status is retained.
If no, go to 8).


Retention of Grandfathering Status
6) Have substantial modifications been made to the application after February 12, 2025? If yes,
then the grandfathered status is lost. Go to 8) to see if footnote 4 can be used.
If no, go to 7).

Footnote 4 – Regardless of grandfathering status, footnote 4 deems certain ZMAP, ZCPA, and ZRTD
approvals to have included a SPEX approval, and allows an applicant to obtain approval of an
administrative application for a data center use based on just the ZMAP, ZCPA, or ZRTD approval.
8) Is the administrative application subject to an approved ZMAP, ZCPA, or ZRTD application? If
yes, go to 9).
If no, go to 13).

9) Was the ZMAP, ZCPA, or ZRTD approved on or before March 18, 2025? If yes, go to 11).
If no, go to 10).

10) Was the ZMAP, ZCPA, or ZRTD grandfathered at the time it was approved? If yes, go to 11).
If no, go to 13).

11) Do the proffers, CDP, or some combination of the proffers and CDP, for the ZMAP, ZCPA, or
ZRTD detail a specific data center use? If yes, go to 12).
If no, go to 13).

12) Is the ZMAP, ZCPA, or ZRTD limited to the data center use? If yes, then the legislative
application is deemed to include a SPEX approval.
If no, go to 13).


Vested Rights – Regardless of grandfathering and footnote 4, it is always possible that a legislative
application created a vested right for a data center use and thereby allows for an administrative
application to be approved without a SPEX. A vested rights determination will be needed.
13) Does an approved legislative application establish a vested right for a data center use? If yes,
then the administrative application may continue without a SPEX.
If no, then a SPEX is needed.

Use of Footnote 3
Footnote 3 – This footnote allows for minor modifications to be made to any approved site plan
without the need for a SPEX approval when such modifications are of the kind described in
10.11.01.H. of the Zoning Ordinance. The ability to use this footnote does not depend on
grandfathering or any specific approval date.
1) Is the approved Site Plan for a data center use? If yes, go to 2).
If no, then applicant cannot use footnote 3.

2) Is the approved Site Plan subject to an approved legislative application? If yes, go to 3).
If no, then applicant can use footnote 3.

3) Does the minor modification pursuant to footnote 3 conflict with the legislative application? If
yes, then the legislative application needs to be amended.
If no, then applicant can use footnote 3.
